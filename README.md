## 🔒 系統安全驗證規範

- 本系統設有研習內部專屬門禁保護機制。
- 前端驗證採用瀏覽器原生 Web Crypto API `crypto.subtle.digest('SHA-256', ...)` 進行無明文單向雜湊比對。
- 驗證成功後自動於本機持久化保存登入狀態（`localStorage`）。
- 頂部導覽列提供「🔒 鎖定」按鈕，方便隨時登出或重新鎖定系統。

## 🎛️ 網站核心功能與視覺化亮點

1. **頂部自訂視覺切換控制項**：
   - 🔠 **3 段字型大小**：`[中]` (標準 16px)・`[大]` (舒適 18.5px)・`[特大]` (清晰 21px)，自由適配不同螢幕與年齡層。
   - 🎨 **4 色主題布景**：
     - `淺`：典雅明亮雪白・暖灰背景・深色閱讀字體。
     - `深`：經典曜石星空・深邃黑藍背景・金色光澤。
     - `綠`：聖誕冷杉翠綠・松針深綠色調・祖母綠與金黃光影。
     - `藍`：極地冰晶湛藍・深海湛藍背景・冰霜天藍光澤。
   - 所有字級與主題切換皆即時生效並自動儲存於 `localStorage`。

2. **多維分頁標籤導航系統**：
   - **🎛️ 提示詞產生工作室 (Studio)**：完整實作 18 維度選單，內建**一鍵載入第二十二章官方預設專案**，即時生成中文設定摘要、首幀正面 Prompt、影片動態 Prompt、獨立負面詞與 10 秒逐秒分鏡表，支援獨立一鍵複製。
   - **📑 8 大主題分類架構 (Categories)**：以卡片化視角瀏覽 8 大模組職責，一鍵跳轉對應章節。
   - **📚 25 章指令總覽庫 (Chapters)**：支援分類膠囊即時過濾、即打即搜關鍵字搜尋、目錄跳轉、全部展開/收合與單章一鍵複製。
   - **🌟 30 種電影特效盒 (Effects)**：視覺化矩陣卡片，點擊即可將特效帶入工作室產生器。
   - **👥 七人角色一致性 (Consistency)**：男主 M01 與六女神 F01～F06 設定卡與「四後二前」站位圖解。
   - **💼 商業廣告與貼圖 (Commercial)**：10 秒廣告節奏軸與 LINE 貼圖留白規準。
   - **📜 原文指令總覽 (Master Prompt)**：完整 Markdown 全文閱覽與一鍵複製全文大按鈕。

3. **純前端 Web Audio 與 Canvas 特效**：
   - 採用純原生 Web Audio API 合成輕柔清脆的聖誕鐘琴互動音效（支援一鍵靜音）。
   - 輕量化 60fps 微風飄雪粒子效果（支援一鍵暫停/開啟）。
