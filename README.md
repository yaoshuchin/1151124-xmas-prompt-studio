## 🔒 系統安全驗證規範

- 本系統設有研習內部資源門禁保護機制。
- 前端驗證採用原生 Web Crypto API `crypto.subtle.digest('SHA-256', ...)` 進行無明文單向雜湊比對。
- 驗證成功後自動於本機持久化保存登入狀態（`localStorage`）。
- 頂部導覽列提供「🔒 鎖定」按鈕，方便隨時登出或重新鎖定系統。

## 📖 系統簡介

《隨心 AI Studio 2026 聖誕魔法宇宙 V4.0》是一套針對頂級影視生成模型（ChatGPT-4o、Claude 3.5 Sonnet、Gemini 1.5 Pro、NotebookLM、Grok Imagine、Google Flow Veo 3.1、可靈 Kling、Runway Gen-3、Seedance 海螺）打造的電影級提示詞工程架構。

本系統完整繼承 V3.0 的核心功能，並全面強化：
1. **三大旗艦引擎**：A 聖誕 AI 生圖、B 電影特效與短劇導演、C 商業廣告與商品展示。
2. **七人角色一致性鎖定**：嚴格執行「一男六女」恰好七人模式，男主角 M01 沿用真實照片臉型神韻，六位女神 F01～F06 具備獨立辨識五官與造型，堅持「換裝換景不換臉」。
3. **30 種聖誕電影特效矩陣**：從「聖誕星光降臨」到「終極聖誕魔法大合奏」，每一項特效皆嚴格設定穩定畫面、觸發時間、動態弧線與尾幀銜接規準。
4. **電影短劇逐秒分鏡系統**：標準 10 秒電影節奏（0-2s 穩定開場、2-4s 人物互動、4-7s 特效爆發、7-9s 驚喜反饋、9-10s 穩定尾幀）。
5. **C 引擎商業廣告旗艦版**：商品外觀色彩 100% 鎖定，絕不虛構規格與數據，整合 10 秒短影音廣告節奏與社群導購文案。
6. **LINE 聖誕貼圖引擎**：落實「先單張後總覽」、四周預留 25% 安全留白與真 Alpha 透明 PNG 交付清單。

## 🎛️ 網站核心功能與互動亮點

- **提示詞產生工作室 (Interactive Studio)**：
  - 完整實作 18 維度選單（引擎、人物組合、鎖定開關、12 種畫風、媒材、場景、服裝、站位、30 種特效、首幀/影片比例、長度、平台、商業目標、執行階段等）。
  - **一鍵載入官方第二十二章預設專案**（七人聖誕魔法森林）。
  - 即時動態生成：中文設定摘要、首幀正面英文提示詞、影片動態提示詞、獨立負面提示詞與 10 秒分鏡表，每個區塊均支援獨立一鍵複製。
- **25 大章節總覽庫 (Chapter Explorer)**：
  - 即時關鍵字搜尋過濾與目錄快速跳轉。
  - 支援「全部展開 / 全部收合」與各章獨立複製。
- **30 種聖誕電影特效盒 (Movie Effects Matrix)**：
  - 30 張視覺化卡片，點擊即可將特效即時載入提示詞工作室或直接複製英文 Prompt。
- **七人角色一致性規準 (Character Consistency Roster)**：
  - M01 唯一男主與 F01～F06 六女神特徵卡與「四後二前」站位圖解。
- **純前端 Web Audio 聖誕音效**：
  - 採用純原生 Web Audio API 合成溫馨清脆的聖誕鐘琴音效，零外載音檔，支援右上角隨時靜音。
- **輕量化 Canvas 飄雪背景**：
  - 60fps 微風輕盈飄雪粒子效果，支援右上角一鍵暫停/重啟。
- **一鍵複製全篇 Master Prompt**：
  - 支援將全篇 25 章完整提示詞以 Markdown 格式一鍵複製至大模型中使用。

## 🚀 本地預覽與運行

使用任意靜態伺服器即可直接啟動：

```bash
# 使用 Python 內建 HTTP 伺服器
python -m http.server 8080

# 或使用 Node.js http-server
npx http-server -p 8080
```

開啟瀏覽器前往 `http://localhost:8080`，輸入研習通行碼即可解鎖體驗。
